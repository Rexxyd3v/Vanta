# Bag equipment art

Original combat knife, kukri and three-cell throwable atlas generated with imagegen, matching the existing VANTA assault-rifle sprite's grayscale cartoon style. Transparent alpha is preserved. Runtime materials supply Default, Silver, Neon Edge and Carbon melee finishes. Utility atlas order is frag grenade, poison smoke, flashbang.

Inventory contains all eight owned guns, both melee models and three throwable types. Bag 1/2/3 configuration and per-bag finishes are saved in vanta-settings.cfg. No currency, purchases or locks are introduced.
